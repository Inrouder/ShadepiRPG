## Bestätigte neue Vorgaben

1. Epischer Landeanflug an den See und sichtbares Aussteigen beider Figuren.
2. Ein romantischer Moment am See; kurz fliegt der Schatten eines Drachen darüber, begleitet von mystischem Leuchten.
3. Raven nimmt Shadepis Maske ab; eine Kussszene folgt.
4. Shadepis Gesicht darf nicht vollständig sichtbar werden. Ravens Hand verdeckt es, wie vom Nutzer für den nicht lokal vorliegenden Comic beschrieben.
