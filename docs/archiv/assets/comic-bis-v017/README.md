# Historische Comictafeln bis v0.17 · archiviert mit v0.46.2 · CodexAI

Die JPGs stammen aus dem früheren bildschirmfüllenden Comic-Dialogsystem unter `assets/comic/`. Seit v0.18.0 werden sie im Spiel nicht mehr eingeblendet. Sie sind hier als historische Spielgrafik erhalten; keine aktuelle Szenenquelle und kein vom Nutzer hochgeladener vollständiger Originalcomic. Die ursprünglichen Importkonfigurationen dokumentieren den damaligen Pfad, sind im Archiv aber nicht aktiv.

Aktuelle Szenen verwenden Figurenbewegung, Sprechblasen und passende Kontaktatlanten: [Zwischensequenzen](../../../zwischensequenzen.md). Verbindliche Lore-/Nutzerquellen: [Universumsarchiv](../../../universum/README.md).
