# Versionsbezogene Bild- und Filmbelege · v0.46.2 · CodexAI

PNG-, WebP- und Audiovorschauen dokumentieren die im Namen oder zugehörigen Bericht genannte Version. **Eine ältere Aufnahme ist kein aktueller Grafik-Sollstand.** Bilder und Filme bleiben für bestehende GitHub-Links erhalten. Insbesondere `bericht-heroes-new-v045.png` zeigt die inzwischen verworfene Heldenvariante; [aktuell sind die Originale](../original-helden.md).

Die [bebilderte Galerie](../README.md) nennt die Aufnahmeversionen. `.gdignore` verhindert Import dieser Dokumentationsmedien; die Exporte schließen `docs/` aus. Keine neuen Spielgrafiken allein zum Aktualisieren dieser Übersicht erzeugen.
