# Touch-UI-Quellen · v0.63.0 · CodexAI

`source.png` ist die unveränderte Bildgeneratorausgabe (1254×1254, RGBA), entstanden für die Nutzerreferenz eines transparenten Handy-HUDs; keine fremden Logos oder Shooter-Grafiken übernommen. Die neun selbständigen Pixelmotive werden anhand ihrer tatsächlichen Silhouetten von `pack.py` registriert und zentriert. `regions.json` dokumentiert die Quellrechtecke. Packer schreibt nach `assets/ui/touch/` und darf nicht automatisch beim Setup laufen. Die Quellen bleiben vom Spiel-Export ausgeschlossen.

`gallery.gd` zeichnet den echten Godot-Viewport mit isolierten Testdaten auf. [Arbeitsnachweis](../../docs/arbeiten/touch-hud-v063.md).
